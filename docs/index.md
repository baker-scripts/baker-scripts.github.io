# Baker Scripts

Open-source tools and scripts for Plex, Starr apps, and server administration.

## Projects

| Project | Description | GitHub |
|---------|-------------|--------|
| [StarrScripts](projects/StarrScripts.md) | Bash scripts for Starr apps (Radarr, Sonarr, Lidarr, Readarr) — custom formats, naming, and automation | [baker-scripts/StarrScripts](https://github.com/baker-scripts/StarrScripts) |
| [Scripts](projects/Scripts.md) | Personal server administration scripts and shell utilities | [baker-scripts/Scripts](https://github.com/baker-scripts/Scripts) |
| [autodns](projects/autodns.md) | Lightweight DNS updater — automatically syncs DNS records from an accessible URL, secured with a unique ID | [baker-scripts/autodns](https://github.com/baker-scripts/autodns) |
| [docker-compose-debugger](projects/docker-compose-debugger.md) | Browser-based Docker Compose debugger — redacts secrets, shows service cards, and generates markdown tables for support channels | [baker-scripts/docker-compose-debugger](https://github.com/baker-scripts/docker-compose-debugger) |
| [docs-templates](projects/docs-templates.md) | MkDocs documentation templates — templatized guides for Plex servers, with variable substitution and interactive setup | [baker-scripts/docs-templates](https://github.com/baker-scripts/docs-templates) |
| [pmm-config](projects/pmm-config.md) | Kometa (Plex Meta Manager) configuration — collection templates, overlays, and metadata management | [baker-scripts/pmm-config](https://github.com/baker-scripts/pmm-config) |
| [qui_workflows](projects/qui_workflows.md) | qui automation workflows for qBittorrent torrent lifecycle management | [baker-scripts/qui_workflows](https://github.com/baker-scripts/qui_workflows) |
| [RedditModLog](projects/RedditModLog.md) | Automated Reddit moderation log publisher — writes mod actions to a subreddit wiki page on a schedule | [baker-scripts/RedditModLog](https://github.com/baker-scripts/RedditModLog) |

## About

Baker Scripts is a collection of open-source tools maintained by [bakerboy448](https://github.com/bakerboy448), focused on media server automation, Starr app configuration, and infrastructure management.

All projects are available on [GitHub](https://github.com/baker-scripts).
