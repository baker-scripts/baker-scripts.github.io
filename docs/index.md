# Baker Scripts

Open-source tools and scripts for Plex, Starr apps, and server administration.

## Projects

| Project | Description |
|---------|-------------|
| [StarrScripts](projects/StarrScripts.md) | Bash scripts for Starr apps — custom formats, naming, and automation |
| [Scripts](projects/Scripts.md) | Server administration scripts and shell utilities |
| [autodns](projects/autodns.md) | Lightweight DNS updater — syncs DNS records from an accessible URL |
| [docker-compose-debugger](projects/docker-compose-debugger.md) | Browser-based Docker Compose debugger — redacts secrets, generates markdown |
| [docs-templates](projects/docs-templates.md) | MkDocs documentation templates — templatized guides with variable substitution |
| [pmm-config](projects/pmm-config.md) | Kometa (Plex Meta Manager) configuration — collection templates and overlays |
| [qui_workflows](projects/qui_workflows.md) | qui automation workflows for qBittorrent torrent lifecycle management |
| [RedditModLog](projects/RedditModLog.md) | Automated Reddit moderation log publisher |

## About

Baker Scripts is a collection of open-source tools maintained by [bakerboy448](https://github.com/bakerboy448), focused on media server automation, Starr app configuration, and infrastructure management.

All projects are available on [GitHub](https://github.com/baker-scripts).
