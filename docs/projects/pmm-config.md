# pmm-config

Kometa (formerly Plex Meta Manager) configuration files for automated Plex library management: collections, overlays, and metadata.

<div class="bs-actions" markdown="0">
  <a class="bs-btn bs-btn--primary" href="https://github.com/baker-scripts/pmm-config">View on GitHub →</a>
</div>

## Highlights

- Movie collection templates: best-of, curated, MCU, holidays, and themed sets.
- TV collections and network-based groupings, plus metadata configs.
- Video overlay definitions and custom collection posters.
- Hidden helper collections for refreshing recently-aired and unmatched items.

File-by-file structure and usage with Kometa: **[GitHub README →](https://github.com/baker-scripts/pmm-config#readme)**
