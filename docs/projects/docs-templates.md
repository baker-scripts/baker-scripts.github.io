## Highlights

- A ready-to-fork Plex server guide with variable substitution throughout.
- Interactive setup script that fills in your values, or edit `mkdocs.yml` by hand.
- Drops into an existing MkDocs repo, or stands alone.
- Deploys via GitHub Pages, Docker, or local `mkdocs serve`.

Variable reference, setup options, and theme features: **[GitHub README →](https://github.com/baker-scripts/docs-templates#readme)**
