# Scripts

Utility scripts for self-hosted infrastructure management: DNS sync, shell aliases, tmux helpers, and Android TV deployment.

<div class="bs-actions" markdown="0">
  <a class="bs-btn bs-btn--primary" href="https://github.com/baker-scripts/Scripts">View on GitHub →</a>
</div>

## Highlights

- `docker_aliases.sh`: Docker Compose wrapper with 1Password secret resolution, fzf integration, and Dozzle group management.
- `nextdns_sync.py`: syncs NextDNS profile settings (allowlist, denylist, security, privacy).
- `tmux_session_picker.sh`: auto-creates a tmux session on SSH login with a running-process table.
- `projectivy-deploy.sh` and `androidtv-app-sync.sh`: install and checksum-pin apps on Android TV devices over ADB.
