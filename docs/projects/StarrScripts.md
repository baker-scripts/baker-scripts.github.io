# StarrScripts

Bash scripts for Starr apps (Radarr, Sonarr, Lidarr, Readarr): custom formats, naming, duplicate management, and update automation.

<div class="bs-actions" markdown="0">
  <a class="bs-btn bs-btn--primary" href="https://github.com/baker-scripts/StarrScripts">View on GitHub →</a>
</div>

## Highlights

- `qui-xseed.sh`: triggers a [qui](https://github.com/autobrr/qui) cross-seed search when Radarr or Sonarr finishes an import.
- `qbm-api-trigger.sh`: fires [QbitManage](https://github.com/StuffAnThings/qbit_manage) commands per torrent hash via the Web API.
- Radarr and Sonarr duplicate finders, plus a non-destructive folder-merge utility.
- Updater scripts for QbitManage, Kometa, Omegabrr, and Plex-Image-Cleanup.
- Housekeeping: ZFS snapshot cleanup, config backup, fail2ban config dump.

Full script list, requirements, and configuration: **[GitHub README →](https://github.com/baker-scripts/StarrScripts#readme)**
